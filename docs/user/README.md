# Keepsake user guide

Keepsake keeps your PC game saves in step between your devices: SteamOS and Bazzite handhelds, Linux PCs and Windows PCs. It stores them in your own cloud storage. It never overwrites a save without asking, and every save it replaces can be brought back.

## Getting started

Pick the guide for your device:

- [Handheld with Decky Loader](getting-started-handheld.md): Steam Deck, Legion Go, ROG Ally and others, on SteamOS or Bazzite.
- [Linux PC](getting-started-linux-pc.md): a desktop or laptop, with or without Decky.
- [Windows PC](getting-started-windows.md).

Set Keepsake up on one device, then on the next. Games whose saves already match link up silently. Any that differ ask you which save to keep.
