# Haversack user guide

Haversack keeps your PC game saves in step between your devices: SteamOS and Bazzite handhelds, Linux PCs and Windows PCs. It stores them in your own cloud storage. It never overwrites a save without asking, and every save it replaces can be brought back.

## Where things are

Haversack was called Keepsake until version 0.51.0. Updating moved everything across, and nothing was lost ([Updates](updates.md)).

Haversack's page has seven sections in its sidebar, each with its own entries:
- **Play:** Now playing and Advisor.
- **Saves:** Games, Conflicts, History, Activity, Import and export.
- **Games and devices:** Moving games, Other devices, Emulators, Disk use.
- **Device:** Device status, Power, Battery, Fans, Controllers, Reconnect help, More device settings.
- **Install.**
- **Settings:** General, Cloud, Sync and safety, Modules, Quick menu, Updates, Help.
- **Diagnostics:** Health, Device checks, Tools, Logs.

This guide is also in Haversack itself, under **Settings**, **Help**, so you can read it on the handheld.

The quick access menu shows the game you are playing, games on their way between your devices, and anything that needs you. The desktop app has the same sections down the left.

## Getting started

Pick the guide for your device:

- [Handheld with Decky Loader](getting-started-handheld.md): Steam Deck, Legion Go, ROG Ally and others, on SteamOS or Bazzite.
- [Linux PC](getting-started-linux-pc.md): a desktop or laptop, with or without Decky.
- [Windows PC](getting-started-windows.md).

Set Haversack up on one device, then on the next. Games whose saves already match link up silently. Any that differ ask you which save to keep.
