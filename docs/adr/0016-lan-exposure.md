# ADR-0016: LAN exposure for Replication

- Status: proposed (slice C0, awaiting Peter's approval; the transport itself is decided in slice 16)
- Date: 15 November 2026
- Deciders: Peter (owner)
- Sources: `docs/build-prompt-v2.md` sections 4 (P17), 6.2, 8.2 and 12 (slices 16 to 18); research sections 4.4, 4.9 and 4.10

## Context

Replication copies games between the two handhelds over the home network. That needs a listening socket in the plugin backend, which v1 never had. A listener on a handheld that travels to other networks is a new attack surface (threats T42, T43 and T55).

## Decision

1. **Off by default.** The Replication module is off by default, and its listener is a separate switch inside it, also off by default. Enabling either by default is an escalation item.
2. **Bound narrowly.** The listener binds only to the LAN interfaces the user selects, never to all interfaces by default. Default port TCP 47110, configurable, never one of 8080 (Decky CEF debugging), 8384, 27040 (Steam LAN transfer) or 1714 to 1764 (KDE Connect).
3. **Paired peers only.** Every request except discovery and the pairing handshake requires a paired peer over authenticated encryption using stdlib `ssl`. No custom cryptography. Slice 16 chooses between mutual TLS with self-signed certificates generated by system `openssl` (pinned fingerprints) and TLS-PSK through `SSLContext` PSK callbacks. If neither works on the device's Python, stop and escalate.
4. **Pairing.** Started by the user on one device. A 6-digit code is entered on the other. The window is time-boxed and attempts are rate-limited. Paired peers are listed in Settings with revoke.
5. **Discovery.** mDNS / DNS-SD on stdlib sockets if slice 16 shows it is viable. Manual address entry is always available.
6. **Firewall.** Keepsake detects an active firewalld (detection only, ADR-0018) and an unreachable port, then shows the exact, port-specific command for the user to run. It never runs it.
7. **Canonical messages.** Peer messages and manifests carry no absolute paths, usernames, compatdata IDs or SD card labels (P10 amended).
8. **Power.** A sleep inhibitor is held only while transferring. Transfers pause below 30 percent battery unless charging, and while a game runs on either device by default.

## Consequences

- Slice 16 is a measurement spike with its own ADR selecting the transport. Slices 17 and 18 build on it, and the protocol is frozen when slice 18 merges.
- When the module or listener is off, no socket is open. A test asserts this.
- Bazzite's default firewall means first-run guidance is part of the slice 17 acceptance.
